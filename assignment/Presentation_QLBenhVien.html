A — Mô tả bài toán

Dữ liệu bệnh viện đang rời rạc

Sổ sách và bảng tính riêng lẻ theo từng khoa khiến việc tra cứu lịch sử điều trị, tổng hợp chi phí và kiểm soát tồn kho trở nên khó khăn.

Mục tiêu: xây dựng một CSDL quan hệ thống nhất, liên kết toàn bộ vòng đời điều trị của bệnh nhân — từ tiếp đón đến xuất viện và thanh toán.

  • Quản lý hồ sơ bệnh nhân, bảo hiểm y tế, lịch hẹn và nhập viện.
  • Quản lý chẩn đoán, kê đơn thuốc và phác đồ điều trị gắn với dịch vụ y tế.
  • Quản lý xét nghiệm, chẩn đoán hình ảnh và mẫu bệnh phẩm.
  • Quản lý nhân sự, khoa phòng, lịch trực — bao gồm chuyên môn hóa Bác sĩ/Điều dưỡng.
  • Quản lý chuỗi cung ứng dược phẩm & vật tư y tế theo lô.
  • Quản lý tài chính viện phí: hóa đơn, thanh toán, bồi thường BHYT.

C.1 — Chuyển mô hình ERD sang mô hình quan hệ

Quy tắc chuyển đổi được áp dụng nhất quán

  • Thực thể mạnh → một bảng, khóa chính → PRIMARY KEY.
  • Thực thể yếu (Phiếu xuất kho) → khóa chính là tổ hợp (khóa chủ + khóa bộ phận).
  • Quan hệ 1:N → khóa ngoại ở phía "N", NOT NULL nếu toàn phần.
  • Quan hệ M:N → bảng trung gian chứa 2 khóa ngoại.
  • IS-A (Bác sĩ/Điều dưỡng) → khóa chính đồng thời là khóa ngoại tới Nhân viên.
  • Đệ quy (Bác sĩ tham vấn) → khóa ngoại tự tham chiếu ngay trong bảng BAC_SI.
  • Tam nguyên → một bảng riêng chứa cả 3 khóa ngoại tham gia.
  • Chu trình phụ thuộc KHOA→BÁC SĨ→NHÂN VIÊN→KHOA → phá vỡ bằng ALTER TABLE sau khi đủ 3 bảng.

F — Cài đặt CSDL bằng T-SQL

Từ chu trình phụ thuộc đến khóa ngoại an toàn

-- Phá vỡ chu trình KHOA → BÁC SĨ → NHÂN VIÊN → KHOA
ALTER TABLE KHOA
    ADD BS_MaBS_TruongKhoa VARCHAR(50)
        UNIQUE REFERENCES BAC_SI(BS_MaBS)
GO

-- Ràng buộc CHECK bổ sung
ALTER TABLE PHIEU_XUAT_KHO
  ADD CONSTRAINT chk_mot_loai CHECK (
    (TH_MaThuoc IS NOT NULL AND VT_MaVatTu IS NULL)
    OR (TH_MaThuoc IS NULL AND VT_MaVatTu IS NOT NULL)
  )
GO

  • 9 câu lệnh ALTER TABLE (khóa ngoại liên phân hệ + CHECK)
  • 14 chỉ mục (INDEX) trên các cột khóa ngoại hay truy vấn
  • 581 dòng dữ liệu mẫu, tôn trọng toàn vẹn tham chiếu
G.1 — Câu lệnh SELECT

-- JOIN 4 bảng minh họa quan hệ TAM NGUYÊN
SELECT nv.NV_Ten AS BacSi,
       bn.BN_HoTen AS BenhNhan,
       dv.DV_TenDichVu, thdv.THDV_NgayThucHien
FROM THUC_HIEN_DICH_VU thdv
JOIN NHAN_VIEN nv ON thdv.BS_MaBS = nv.NV_MaNV
JOIN BENH_NHAN bn ON thdv.BN_MaBN = bn.BN_MaBN
JOIN DICH_VU_YTE dv ON thdv.DV_MaDichVu = dv.DV_MaDichVu
GO

CREATE TRIGGER trg_CapNhatTongChiPhiHoaDon
ON HOADON_CHITIET_DICHVU AFTER INSERT AS
BEGIN
  UPDATE hd SET hd.HD_TongChiPhi = hd.HD_TongChiPhi + t.TongThem
  FROM HOA_DON hd
  JOIN (SELECT HD_MaHD, SUM(ThanhTien) AS TongThem
        FROM inserted GROUP BY HD_MaHD) t ON hd.HD_MaHD = t.HD_MaHD
END
